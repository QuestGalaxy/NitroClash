# NitroClash - Post-Apocalyptic NFT Racing

This is a modern, immersive recreation of the NitroClash project using Next.js 15, Tailwind CSS, and Framer Motion.

## Design Concept
- **Theme**: Mad Max / Post-Apocalyptic
- **Style**: Dark, gritty, metallic, with neon accents.
- **Tech Stack**:
  - **Framework**: Next.js 15 (App Router)
  - **Styling**: Tailwind CSS
  - **Animations**: Framer Motion
  - **Icons**: Lucide React

## Folder Structure
- `src/app`: Main application pages and global styles.
- `public/img`: Assets migrated from the original project.

## How to Run
1. Navigate to the `NitroClash` directory.
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
